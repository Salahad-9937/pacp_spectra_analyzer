# PACP SPECTRA ANALYZER

## Суть проекта
PACP Spectra Analyzer — это легковесный десктопный инструмент для быстрого первичного анализа гамма-спектров, полученных со сцинтилляционных детекторов. 

Главная цель программы — предоставить исследователю максимально простой и быстрый способ посмотреть на сырые данные, усреднить повторные измерения и вычесть фоновый шум, без необходимости загружать тяжелые и перегруженные функциями научные комбайны.

## Целевая аудитория
Физики и исследователи, работающие со сцинтилляционной спектрометрией, которым нужно "здесь и сейчас" оценить качество снятого спектра, проверить наличие пиков и получить базовый очищенный от фона результат для дальнейшей работы.

## Философия и дизайн
- **Фокус на скорости и простоте.** Программа запускается, открывается папка с измерениями, и через пару кликов результат уже на экране. Никаких сложных настроек, проектов и баз данных.
- **Научный минимализм.** Интерфейс выдержан в спокойном светлом стиле, характерном для лабораторного ПО. Ничего не должно отвлекать от самих данных (графиков и чисел).
- **Отсутствие "синдрома швейцарского ножа".** Программа не стремится охватить все возможные задачи спектрометрии. Это инструмент для *первичного* анализа. Если для глубокого анализа (сложная калибровка, фитинг, автоматический поиск изотопов) нужны другие инструменты — это нормально. PACP делает свою узкую задачу и делает её хорошо, оставляя возможность для органичного добавления новых функций в рамках этой же простой концепции.

## Базовый сценарий использования
1. Исследователь снимает серию спектров (образцы и фоны) и складывает их в одну папку.
2. Запускает программу и указывает эту папку.
3. Программа автоматически распознает файлы по устоявшемуся формату именования.
4. Пользователь визуально оценивает спектры на графике, сравнивает их.
5. При необходимости запускает базовую обработку: программа сама усредняет дубли и вычитает соответствующий фон.
6. Результаты сохраняются тут же, в понятном текстовом формате, готовые к дальнейшему использованию.

## Платформенная ориентация
Проект разрабатывается исключительно для десктопных окружений (Windows, Linux), так как работа с локальными массивами текстовых файлов измерений подразумевает классический рабочий процесс за ПК. Мобильные и веб-платформы не рассматриваются в рамках концепции.
